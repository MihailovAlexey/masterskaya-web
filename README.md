# Мастерская — публичные файлы интерфейса

Готовая статическая сборка Telegram Mini App. Содержит только файлы, которые браузер загружает с публичного сайта. Исходники разработки находятся в отдельном закрытом репозитории.

Рабочие данные доступны только через авторизованный API Supabase. Токен бота, ключи сервера, клиентские ремонты и платежи в этом репозитории не хранятся. Внешний браузер без Telegram-авторизации не получает рабочие данные.

Timeweb App Platform: React, Node 24, установка `npm ci`, сборка `npm run build`, результат `dist`. Автоматическое обновление не требуется: публикуется проверенный коммит сборки.
